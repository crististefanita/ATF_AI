1. Executive Context - Context Executivscope, audit scor si limite de intelegere colapsate
Verdict

ATF core este un pachet de contracte framework, nu un set de teste business clasice pentru un magazin. Business-ul lui este increderea operationala: fiecare echipa poate rula API/UI smoke, poate primi raport Extent/Allure coerent, poate vedea failure placement, screenshot-uri, profile si un verdict aggregate. Ultima dovada publicata pentru sweep-ul core este 441 passed / 0 failed / 0 skipped in raportul aggregate Extent.
