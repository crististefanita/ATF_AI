Linkuire comuna a artefactelor LINKS PROOF PORTABLE

  • Defineste cum se leaga orice claim publicat de un artefact redeschisibil.
  • Shared stabileste forma linkului, proximitatea si auditabilitatea; MCP si Atlas stabilesc ce artefacte sunt obligatorii.
  • Nu accepta linkuri decorative, absolute fragile sau dovezi fara comanda/origin cand raportul pretinde reproducibilitate.
