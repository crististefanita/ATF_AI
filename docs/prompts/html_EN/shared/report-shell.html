Shared Report Shell

This shared primitive defines the reusable report frame used by Reporting, MCP and Atlas references: stable navigation, collapsible sections, score opening, artifact index, and evidence links.

  • Use the Reporting skill for generic rendering mechanics, HTML shell, Extent/Spark, runtime audit and shared primitives.
  • Use MCP for package close-out evidence and final report gates.
  • Use Atlas for business-understanding quality and trace judgment.

Executable Contract

The shared rule is implemented in com.endava.ai.core.reporting.htmlcontract. It validates shared chrome, score wall, graph visual primitives and the declared profile through HtmlReportContract. It must not impose MCP vocabulary on Atlas.
