3.6 Same-package vs fresh ROOT_RUNdistinctions of legality
Legend
  • same-package blocked nu inseamna application exhausted.
  • fresh ROOT_RUN legal nu inseamna automat launch-ready now.
  • Fresh round legality comes from cold handoff; launch-ready comes after real prepare + pretrain.
  • If an agent confuses these three verdicts, the next packet starts from false memory.
  • META_ITERATION_COUNT requires consuming the entire active window; any closure below it must be treated as a defect or severe blocker.
  • Before the first code step, the brief must explicitly say how you will get to tests produced = x / ROUND_TARGET_TEST_COUNT and to runs consumed = n / META_ITERATION_COUNT.
