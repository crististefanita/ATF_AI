1.1 Minimum contract
  • The seed is the input, not the verdict.
  • The frontier is business-first: actor, intent, visible step, result.
  • The run produces auditable tests for the chosen anchor or teaches the severe blocker.
  • Without a visible business result and explainable UI proof, the flow remains an investigation.
  • Minimal teaching: claim UI, visible anchors, local result, blocker and lesson.
  • Strict document for visible UI border.

2.3 Frontier UI: owned / partial / blockedUI adapter specific reading
Legend
  • owned requires a stable visible result and explainable UI.
  • partial can repair support without gaining a new business identity.
  • blocked means the UI does not cold-close the frontier, not just that the test was inconvenient.
Frontier qualityHe must answerIf the answer is weak
expected business delta what new truth about the application changes the business map, not just the visible proof?

  • reject selector-only
